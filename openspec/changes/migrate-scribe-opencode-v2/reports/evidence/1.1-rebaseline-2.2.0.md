## Results relevant to Scribe

The OpenAPI documents contain 124 and 130 paths respectively. Among the Scribe-used API families, operation definitions changed at `/api/agent`, `/api/event`, `/api/model`, `/api/session/{sessionID}/agent`, `/api/session/{sessionID}/fork`, `/api/session/{sessionID}/interrupt`, and `/api/session/{sessionID}/model`. Experimental instruction-entry routes changed at `/api/experimental/session/{sessionID}/instructions/entries` and its `{key}` route; `/api/experimental/session/{sessionID}/wait` also changed. These are schema/operation changes, not proof that a particular client call remains compatible.

Other observed OpenAPI changes include `/api/project`, `/api/project/{projectID}`, `/api/permission/saved/{id}`, and several background/revert routes; `/api/plugin/gui` was added; `/api/experimental/voice/session/{sessionID}/instructions` was removed. These should not be treated as Scribe contract changes absent a corresponding adapter use.

The selected public OpenAPI documents are the experimental HTTP API surface and do not, by themselves, settle SDK-only operations and the full `IAgent` mapping. This report does not establish authentication/location behavior, binary/source equivalence, runtime pairing, or host behavior.
