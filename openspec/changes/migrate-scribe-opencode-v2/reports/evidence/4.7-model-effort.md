# 4.7 Model and effort selection — local evidence

Status: **local adapter and UI-routing unit evidence; no live provider or actual-host claim.** `setModel` now validates the exact native short-reference shape and retains a default only in the agent instance. It applies that selection through native `session.switchModel` in the existing prompt path; it performs no configuration reads/writes and does not mutate global OpenCode configuration.

## Behavior covered

- Provider/model references require a qualified provider, non-empty model and (when present) non-empty variant; model IDs may contain `/`. Invalid selections fail with a bounded generic error before replacing the cached default.
- The selection persists across reconnects in the same workspace and is cleared when the effective workspace changes.
- Normal and edit/resend prompts share `sendMessage`; explicit request model/effort take precedence. A cached variant is not copied to a different explicit model. Missing variants are omitted from native switch arguments.
- With no explicit or cached model/effort, native `session.switchModel` remains absent, preserving native defaults.
- Host `setModel` routing and existing webview model/effort selection scenarios remain unchanged except the host comment now describes in-memory behavior.
