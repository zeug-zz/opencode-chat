- `packages/agents/opencode/src/opencode-agent.ts` now builds native `default_agent: "scout"` and `agents` entries using `permissions` arrays; there is no Scribe overlay `agent` or `permission` object.
- Scout is `mode: "all"`; it receives explicit `execute`, ordinary read/discovery/web/question actions, the reviewed research prefixes, and `subagent` only for resource `chat-research-worker`. The leading wildcard deny leaves shell, edit, and unrelated tools denied. - Restricted reviewer entries from `restricted-review-overlay.ts` are native hidden subagents with deny-only `permissions` entries for the restricted and dynamic authority names. They receive no `execute` or tool allow rules. `restricted-review-provider.ts` validates this native entry shape.
- Hindsight allows remain exact tool-name entries. Confirmation-gated retention/confirmation rules are only composed for Scout and Build when the integration's existing capability/backend gates pass; the worker receives none.
- `buildChatOverlay` composes the same native agent policy for both private-child launch paths. Existing sandbox-on/off unit coverage compares the semantic `agents` section, but does not prove effective runtime parity.
