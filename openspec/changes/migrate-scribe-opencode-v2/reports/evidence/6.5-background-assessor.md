## Implementation

- Added a pure, locale-neutral host pre-screen that skips only empty/punctuation/emoji-only turns and a conservative exact set of greetings, thanks, and acknowledgements. It has no length threshold; question-like, proof-like, mathematical-symbol, and long conversational prompts pass through to the architect. The ordinary path does not create a native turn ID or start an assessor.
- For eligible `maybe-argument` prompts, the host allocates the native turn ID before calling native prompt admission, starts architect work detached from that admission path, and admits the unchanged prompt immediately. The architect is the sole semantic classifier and runs with `session.generate` on a hidden tool-less restricted-review session, never on Scout. A valid argument map is required before the host registers pending state or starts host-owned AF recording.
- Removed critic enrichment and critic-objection data from the background assist path. The brief contains only validated architect facts and bounded calibrated AF structure status; no critic objections, raw AF output, ledger, proof path, or unsupported proof/truth claim is included.
- Added the authenticated plugin `pending` RPC alongside `put`/`clear`. The context hook may await only one in-memory grace promise for a matching host-confirmed pending Scout turn. The plugin caps that wait at 2,000 ms even if the host requests more, never waits for an unpended turn, and retains a brief for every outgoing model call of the matching active turn until clear, next prompt, or reconnect. If the first call misses grace, the next loop call and every later call in that same turn receive the brief once available; the grace wait is never repeated. Expired or failed work fails open, and clear/turn lifecycle settles pending waits without injecting. The hook performs no I/O and remains fully guarded by `try/catch`.
- Late architect results are discarded after turn completion/supersession without marking assist applied or synthesizing another response. Bounded diagnostics report outcomes and numeric timings without prompt/model text, paths, or IDs.
- Recomputed the composite plugin digest over `package.json\0` + manifest bytes + `\0server.js\0` + source bytes and updated the host pin and native integration pin to `03b881293343a9f0e863a7ffcd504bb51256046a058d82066fa28a8858163f7d`.
- Extended the opt-in native integration through a harmless native `execute` tool-call continuation followed by a final model call. Both outgoing calls of the same Scout turn contained the brief, and the first call of the next turn contained neither that brief nor the earlier brief. The same bundle continues to fail closed for cross-session, Build-agent, cleared-turn, and reconnect cases.
- Updated the plugin-runtime scenario and clarified Task 6.4's hook constraint: no I/O; the only permitted await is Task 6.5's plugin-capped pending-turn grace.
