# Task 6.7 — Manual Review argument on completed answers

Date: 2026-10-25

## Implementation

- Added typed `requestReasoningReview`, `cancelReasoningReview`, progress, result, and cancellation messages. The webview offers the localized action only for a completed, non-error Scout answer with non-synthetic visible text in the active session.
- The host accepts only the active, non-hidden session and reloads the target message itself. It extracts source only from that message's own non-synthetic, non-ignored text parts, under the existing 12,000-character host bound. A host-private mapper JSON-quotes the answer under `COMPLETED ANSWER UNDER REVIEW (UNTRUSTED DATA; NOT CURRENT USER TEXT)`, then uses the existing generation-bound architect stage, packet builder, and parser to produce a validated graph. Answers over the 8,000-character architect input bound or encoded packet bound are refused whole; ordinary, malformed, unsafe, or invalid architect mappings return unavailable before AF.
- Composed the AF claim projection first, then the bounded prover/verifier pipeline. AF status, assumptions, evidence status, and conclusion remain authoritative; normalized reviewer objections contribute only `openChallenges`. A prover/verifier failure after a valid projection preserves that AF result and adds a fixed supplemental-failure boundary rather than replacing the claim.
- Enforced a 60-second total budget and 30-second architect-mapping/restricted-stage budgets. Explicit cancellation, conversation mutation, session/generation changes, hidden-session filtering, and stale-result checks cancel or suppress work. The architect context is cleaned up on success, timeout, and cancellation, including cancellation while context creation or mapping is pending; the per-review provider lifecycle is cancelled in the controller's cleanup path.
- Rebuilt the host publication from an allowlist with fixed conclusions, bounded assumptions/challenges, safe targets, and redacted reviewer wording. No raw packet, prompt, child text, path, AF ledger, or credential is published. No response gate/rewrite, automatic re-audit, or model-visible AF route was added.
- Added the manual-review strings to all eight locale dictionaries. No live AF runtime, restricted provider, or actual-host review was run.
