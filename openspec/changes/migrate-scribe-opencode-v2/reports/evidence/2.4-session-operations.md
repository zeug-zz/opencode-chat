# 2.4 Session lifecycle mapping — partial implementation

Status: **PARTIAL — native list/create/get/delete/child-session/fork/revert/unrevert/compact mappings are implemented and hermetically tested. Task 2.4 remains unchecked.** No live OpenCode server, provider, or user configuration was used. Share/unshare are explicitly unavailable because the pinned V2 contract has no API. This is an intermediate adapter state, not V2 functional parity.

## Implemented in this patch

- Added the exact `@opencode/client@2.0.32` agent-package dependency. `OpenCode.make` constructs a native client using the same private child URL and private authorization headers as the existing client. Both client references clear on disconnect, child exit, and startup cleanup.
- `mapV2Session` explicitly validates V2 session identity, project, optional title/parent, timestamps and token/cache shape, and maps those supported fields plus `location.directory` into `ChatSession`. Missing title maps to `Untitled`; malformed required data is rejected.
- Session listing uses native `session.list`, current workspace directory when available, native `cursor.next`, repeated-cursor protection and a 1,000-page hard bound that rejects instead of returning an incomplete list. Child listing uses `parentID`, paginates identically, and rejects foreign-parent results.
- Create sends native `{ title?, location: { directory } }`; get and delete use native `session.get` and `session.remove` with the exact validated ID. Promise-client plain `SessionInfo` results are mapped directly, with no `.data` envelope assumption.
- Fork sends the existing SDK's optional `messageID` anchor as native `before`; pinned source at commit `843a6c514e606b436a7fe713422ace0a93ad3d61` defines the native boundary as `before` and returns the fork with its parent identity. Omitted anchors remain omitted. Fork responses are validated for location and parent.
- Revert stages `{ sessionID, messageID }` (native `files` defaults to `true`), verifies the staged message identity, and fetches authoritative session info. Unrevert calls `revert.clear` and fetches authoritative info. The inspected pinned server source shows stage restores file snapshots and records staged revert state; clear restores the original snapshot and clears that state. Neither operation calls `revert.commit`.
- Summarize uses `session.compact({ sessionID })`. If a model is explicitly provided, it first calls native `session.switchModel` with `{ providerID, id }`; the `ChatSession` model type has no variant field, so no variant is fabricated. The server default path omits model selection. A per-session operation queue serializes compaction/model switch with this adapter's prompts and revert operations.
- Share/unshare throw a bounded `OpenCodeOperationUnavailableError`; the `@opencode/client@2.0.32` declarations and generated implementation inspected in 1.1 expose neither operation. No legacy route fallback, URL fabrication, or success result is used.
