## Task 1.3 cancellation qualification correction

The disposable contract harness defaults to the pinned built-in `@opencode/ai/providers/openai-compatible` package against a loopback OpenAI-compatible HTTP mock; the custom V3 fixture is only selected with `OPENCODE_CHAT_V2_SPIKE_PROVIDER_LANE=aisdk-fixture`. Neither lane proves production-provider parity. Pinned `packages/core/src/aisdk.ts` source constructs no `abortSignal` in `callOptions()` and does not forward Effect's signal into `language.doStream(options)`.
